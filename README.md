# รุ้ง (Rung Browser) - เวอร์ชัน Desktop (Mac / Windows)

สร้างด้วย Electron (Chromium) ใช้ดีไซน์ ธีม และฟีเจอร์ความเป็นส่วนตัวแบบเดียวกับเวอร์ชัน Android

## รันดู
ติดตั้ง Node.js 20 ขึ้นไป แล้วในโฟลเดอร์นี้
```
npm install
npm start
```

## สร้างไฟล์ติดตั้ง .exe / .dmg
**ทางง่ายที่สุด: GitHub Actions (ไม่ต้องมีเครื่อง Mac)**
1. สร้าง repo บน GitHub (ฟรี) แล้วอัปโหลดทั้งโฟลเดอร์นี้ (รวมโฟลเดอร์ .github)
2. แท็บ Actions > Build installers > Run workflow
3. รอราว 10 นาที ดาวน์โหลดไฟล์ .exe และ .dmg จากหน้าผลรัน (Artifacts)

**หรือ build เอง:** `npm run dist:win` (บน Windows) / `npm run dist:mac` (บน Mac) ได้ไฟล์ในโฟลเดอร์ dist

### เรื่องการเซ็นรับรอง (ไม่เซ็นก็ใช้ได้ แต่จะมีหน้าเตือน)
- ไม่เซ็น: Windows ขึ้น SmartScreen (More info > Run anyway), Mac ต้องคลิกขวา > Open ครั้งแรก
- เซ็นแล้วหน้าเตือนหายไป: Windows ต้องซื้อ code-signing certificate (ราว 100-400 USD/ปี), Mac ต้องมี Apple Developer Program (99 USD/ปี)
- ถ้ามีแล้ว ใส่เป็น Secrets ใน GitHub repo ตามชื่อในไฟล์ .github/workflows/build.yml แล้ว build จะเซ็นให้เอง
- ก่อนแจก เปลี่ยน `appId` และ `author` ใน package.json

## ฟีเจอร์
- แถบข้างแบบ Arc: ช่องที่อยู่เว็บ/คำสั่งอยู่บนสุด (ค้นหาแท็บ บุ๊กมาร์ก ประวัติ พร้อมกัน), ปักหมุด, Spaces, แท็บส่วนตัว
- ดีไซน์แนว Apple (ดู DESIGN.md): โหมดสว่าง/มืด, สีเน้น 8 แบบ, แถบข้างลอยแบบกระจก, Mac ใช้ vibrancy / Windows 11 ใช้ Mica
- คลิกช่องที่อยู่เว็บ: แสดงรายการโปรดและเว็บที่เข้าล่าสุด ซ่อน/แสดงแถบข้างได้
- **บล็อกโฆษณาระดับ uBlock Origin:** กฎกรอง 157,000+ ข้อ (EasyList, EasyPrivacy, uBlock Origin filters, Peter Lowe) ทั้งบล็อกคำขอ ซ่อนกล่องโฆษณา และ scriptlet กรองโฆษณา YouTube กดอัปเดตกฎได้จากเมนู
- **ส่วนขยายสไตล์ Chrome:** เพิ่มจากโฟลเดอร์ที่แตกไฟล์แล้ว (เมนู > ส่วนขยาย) รองรับเฉพาะบางแบบ
- เตือนเว็บแอบอ้างธนาคาร/ไปรษณีย์/กรมสรรพากร, เตือนก่อนโหลดไฟล์ .exe .msi .dmg ฯลฯ
- บังคับ HTTPS, ตัดรหัสติดตามในลิงก์, บล็อกคุกกี้ของเว็บอื่น, ส่ง Do Not Track/GPC, ถามก่อนใช้กล้อง/ไมค์, ปฏิเสธตำแหน่งและแจ้งเตือน
- ทุกการตั้งค่ามีคำอธิบายภาษาง่าย ๆ ว่าเปิดแล้วอะไรจะใช้ไม่ได้
- ค้นหาในหน้า, โหมดอ่าน, ขนาดตัวอักษรเว็บ, บุ๊กมาร์ก, ประวัติ, ตัวจัดการดาวน์โหลด

## ปุ่มลัด (Mac ใช้ Cmd แทน Ctrl)
Ctrl+T แท็บใหม่ | Ctrl+Shift+N แท็บส่วนตัว | Ctrl+W ปิดแท็บ | Ctrl+L ช่องที่อยู่/คำสั่ง | Ctrl+F ค้นหาในหน้า | Ctrl+S ซ่อนแถบข้าง | Ctrl+Shift+R โหมดอ่าน | Ctrl+ +/- ขนาดตัวอักษร | Ctrl+[ ] ย้อนกลับ/ไปข้างหน้า

## ที่ยังไม่มี (มีเฉพาะใน Android)
Boosts, Split View, Peek, เก็บแท็บอัตโนมัติ 12 ชม., ล็อกแอพ

## ข้อจำกัด
- ทดสอบรันบน Linux จำลองจอเท่านั้น ยังไม่ได้ทดสอบบน Windows/Mac จริง
- ส่วนขยาย Chrome รองรับไม่ครบ ตัวจัดการรหัสผ่านอย่าง Bitwarden ยังไม่ได้ยืนยันว่าใช้ได้ ควรลองก่อน
- ตัวตรวจเว็บหลอกลวงตรวจจากชื่อโดเมนเท่านั้น
- ฟอนต์ Inter และ Noto Sans Thai ไลเซนส์ OFL ดู FONT-LICENSE-OFL.txt (บน Mac ใช้ฟอนต์ระบบ), กฎกรองโฆษณามีไลเซนส์ของแต่ละรายการ (EasyList: GPL/CC BY-SA, uBlock filters: GPLv3)
